# 셀렉트마켓 채팅 · 내 컴퓨터에서 AI 테스트하기

탭 3·4의 자유 질문은 AI가 답해요. 클로드 아티팩트 안에서는 자동으로 되지만, 내 컴퓨터에서는 작은 서버가 키를 들고 대신 AI를 불러 줘요. 키는 서버만 알고, 화면(브라우저)에는 전달되지 않아요.

```
브라우저 화면 ──질문──▶ 내 컴퓨터 서버 ──(.env의 키)──▶ 클로드 API
              ◀──답──            ◀──답──
```

## 처음 한 번
1. 프로젝트 맨 위 폴더의 `.env` 파일에 `ANTHROPIC_API_KEY=` 뒤로 공유받은 키를 붙여 넣어요. (없으면 `selectmarket-chat/env.example`을 `.env`로 복사)
2. 터미널에서 설치해요.

```bash
cd selectmarket-chat && npm install
```

## 켜기
```bash
cd selectmarket-chat && npm start
```
브라우저에서 http://localhost:8787 을 열어요. 끄려면 터미널에서 `Ctrl + C`.

## 확인할 것
| 확인 | 기대 결과 |
|---|---|
| 탭 4에서 목록에 없는 질문을 보내기 | 몇 초 뒤 답이 글자 단위로 흘러나오고 "AI 답변" 표시가 붙음 |
| 재고·주문 같은 빠른 질문 | AI 없이 즉시 조회로 답함 |
| 키가 비었을 때 | "키를 넣어 달라"는 안내가 뜸 |
| 서버를 끄고 질문 | "AI 서버에 연결하지 못했어요" 안내가 뜸 |

## 대화 기록 · 신고 · 운영자 피드백 (답변 고도화)
```
사용자 대화 ─▶ 브라우저에 자동 저장(로컬 스토리지) ─▶ 관리자 화면에서 검토
   └ "답변이 잘못됐어요" 신고                         └ 좋음/나쁨 판정 + "이렇게 답해야 해요"
                                                         └ 지침 반영 체크 ─▶ data/guidelines.json
다음 AI 답변 ◀── 서버가 활성 지침을 프롬프트에 붙임 ("지침 N개 적용" 표시)
```
탭 4 오른쪽 위 "관리자" 버튼을 누르면 채팅과 완전히 다른 관리자 콘솔 화면(검은 머리띠, 왼쪽 메뉴)이 열리고, "← 채팅 화면으로"로 돌아와요.

| 화면 | 하는 일 |
|---|---|
| 탭 4 답변 아래 "답변이 잘못됐어요" | 사유(사실과 달라요 / 질문과 상관없어요 / 말투·표현 / 기타)를 골라 신고 |
| 관리자 콘솔 > 대화 기록 | 전체 대화 목록, 신고 통계(건수·신고율·사유별), 탭·답변 방식·상태 필터, 검색, 건별 피드백 |
| 관리자 콘솔 > 지침 | 지침 켜기/끄기, 수정, 적용 탭 선택, 삭제, 직접 추가 |

- 대화 기록은 이 브라우저의 로컬 스토리지에 최대 500건까지 저장돼요. 다른 브라우저·컴퓨터에서는 보이지 않아요.
- 지침은 `data/guidelines.json` 파일에 저장돼요(서버 모드). 클로드 아티팩트 안에서는 브라우저가 직접 지침을 붙여요.
- 서버를 새로 받았다면 `npm start`를 다시 해야 이 기능이 켜져요.

## 자주 막히는 곳
| 증상 | 원인과 해결 |
|---|---|
| "API 키가 올바르지 않아요" | `.env`의 키에 따옴표·공백이 섞였거나 키가 틀림 → 다시 붙여 넣고 서버 재시작 |
| "모델 이름을 찾을 수 없어요" | `.env`의 `ANTHROPIC_MODEL`을 `claude-haiku-5-5`로 바꿈 |
| 첫 글자가 늦게 나옴 | 기본 모델(Opus)은 정확하지만 느림 → `claude-haiku-5-5`로 바꾸면 빨라짐 |
| 이미 쓰는 포트 | `.env`의 `PORT`를 다른 숫자로 바꿈 |
| `.env`를 바꿨는데 그대로 | 서버를 껐다가 다시 켜야 반영됨 |

## 지켜야 할 것
- `.env`는 깃에 올라가지 않아요. 메신저·메일·스크린샷으로 키를 공유하지 마세요.
- 이 서버는 내 컴퓨터(127.0.0.1)에서만 열려요. 외부에 공개하는 용도가 아니에요.
- 클로드 코드에서 이어서 작업할 때는 이 폴더를 열고 "selectmarket-chat/README.md 읽고 이어서 해 줘"라고 요청하면 돼요.
