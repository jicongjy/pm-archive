오늘 다룬 내용

회원가입 약관은 푸터의 전체 약관과 다를 수 있다

가입 화면에 보이는 동의 항목은 가입에 꼭 필요한 것만 골라 보여 줍니다. 푸터에 있는 전체 약관은 서비스가 가진 약관 전체입니다. 그래서 기획할 때 두 목록을 나눠 정책표에 적어야 합니다.

구분내용
가입 화면의 동의 항목가입에 필요한 항목만
푸터의 전체 약관서비스가 가진 약관 전체
관리자 페이지약관을 보고 고칠 수 있는 화면이 있으면 운영이 편해짐

휴면계정 관리와 약관 변경 알림은 마케팅 기회도 된다

휴면계정 안내나 약관 변경 알림은 오래 안 온 사용자를 한 번 깨워 서비스를 다시 떠올리게 할 명분이 됩니다. 다만 비용이 듭니다.

수단알아 둘 점
문자건당 비용이 비싸서 발송 대상과 횟수를 먼저 정해야 함
이메일공짜가 아니고 발송 서비스 비용이 듦
비용 확인클라우드 서비스의 요금 계산기로 발송량별 금액을 미리 계산

UTM은 담당자가 있고 기록해야 하는 관리 대상이다

기록할 것이유
언제, 누가 배포했는지나중에 어느 캠페인 숫자인지 추적
만든 패턴채널 이름이 사람마다 달라지는 것을 막음
보관 방법시트 하나를 만들어 관리하는 팀도 많음

마케팅 유입은 다이렉트, 오가닉, 페이드로 나눠 읽는 용어를 함께 봐 두라는 안내를 받았습니다.

스킬은 프롬프트 덩어리다

스킬은 복사해서 새 대화에 프롬프트로 붙여도 동작합니다. 같은 기능이 서비스마다 다른 이름으로 있습니다.

서비스같은 기능의 이름
ChatGPTGPTs
클로드별도 이름 없음
제미나이Gems

잘 된 작업을 스킬로 만들 때는 "다음에 쓸 수 있도록 내장 스킬로 만들어 줘"라고 요청합니다. 프롬프트 자체를 만들어 달라고 하는 방식을 메타 프롬프팅이라고 부릅니다.

스킬을 부르는 세 가지 방법

방법내용
슬래시 후 이름만입력창에 슬래시를 치고 이름만 입력해 시작
슬래시와 요청 함께이름 뒤에 주소와 채널 목록을 이어 씀. 예: 카카오톡 채널, 뷰티 커뮤니티, 직원 지인 추천
평소 말로"이 링크 UTM 달아서 채널별로 만들어 줘"처럼 말하면 스킬 설명과 맞을 때 알아서 꺼냄. 주소와 채널을 같이 주면 질문 없이 링크와 관리 시트까지 만듦

공개 스킬 플러그인

  • Superpowers를 공식 플러그인 목록에서 카드로 바로 추가하는 시연을 봤습니다. 터미널 명령은 필요 없고, 15개 스킬과 시작 훅 하나가 들어 있습니다.
  • 추가해도 이 대화에 바로 적용되지 않을 수 있어서 새 대화에서 쓰는 것이 확실합니다. 입력창에서 명령어로 동작 여부를 확인하고, 우측 토글이 켜져 있는지 봅니다.
  • 안 된다고 나와도 이유와 대안을 되물을 수 있고, "여기서는 못 써?"라고 물으면 공개된 플러그인을 찾아 줍니다.

안티그래비티는 앱과 IDE로 나뉜다

항목내용
앱과 IDE둘 다 따로 설치. 앱은 흰색 아이콘, IDE는 검정 배경 아이콘에 이름에 IDE가 붙음
시작구글 계정을 준비하고 로컬에 폴더를 만든 뒤 index.html 하나 만들기
확인로그인 여부와 쓸 수 있는 모델, 프롬프트창 하단에서 로그인 확인, 사용량 화면에서 남은 한도 확인
실행로컬 서버를 띄워 브라우저에서 확인

사용 한도와 API 키는 다른 문제다

구분내용
API 키 문제무료 키가 막히면 유료 키로 바꿈
모델 사용 한도API 키와 무관한 코딩 에이전트 사용량. 소진되면 모델을 클로드로 바꿔 작업을 이어 감
실패 공유제미나이가 해결을 못 하면 최대 3번까지 개선을 시도한 뒤 실패 사례를 공유

수업에서 임시로 공유된 키는 당일 비활성화되었습니다. 키를 채팅에 올리는 일은 따라 하면 안 됩니다.

내 실습 1: 내 업무 스킬 2개

만든 순서

  1. 반복하던 깃허브 올리기 절차를 클로드 코드와 정리하고 publish 스킬로 만들었습니다. 올리기 전 점검, 커밋 나누기, 푸시, 결과 보고까지 한 번에 합니다.
  2. 매일 쓰는 학습 노트 작성 절차를 daily-note 스킬로 만들었습니다. 재료 모으기, 빠진 것 묻기, 초안, 회고, 미리보기, 반영 순서입니다.
  3. 월요일과 화요일 노트를 보완하는 세션에서 daily-note 스킬을 실제로 불러 써 봤습니다.

내 실습 3: 클로드 코드 확장 프로그램

클로드 코드를 에디터 확장 프로그램으로 설치해 써 봤습니다. 수업에서 안내한 실습은 다음과 같았습니다.

  1. 온보딩 화면의 버튼을 눌러 readme 만들기
  2. 왼쪽 파일 목록에서 readme.md가 생긴 것 확인
  3. 로컬 실행과 미리보기
  4. 개발자들이 추천하는 편집기 플러그인 보기
  5. 왼쪽 클로드 코드 메뉴를 우클릭해 오른쪽으로 옮기기

배운 점

  • 공개 플러그인을 켜도 이 대화에 바로 적용되지 않을 수 있어서, 새 대화에서 토글이 켜졌는지 확인해야 한다.
  • 안티그래비티는 앱과 IDE로 나뉘어 있다.
  • 이미지 생성이 안 되면 쓰는 모델이 종료되지 않았는지 먼저 본다. 종료된 Imagen 3 대신 Nano Banana 계열로 바꾸니 해결되었다.
  • 에이전트가 멈추면 API 키 문제인지 모델 사용 한도 문제인지 먼저 가른다.
